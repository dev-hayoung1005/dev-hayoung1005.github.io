알게 된 것

1. 위험은 연결되는 순간부터 시작됩니다

주소를 알리지 않은 이 사이트에, 연결 다음 날 새벽 한 해외 IP가 1~2초 사이 서버 비밀번호와 API 키가 담긴 설정 파일(.env, .ssh, .terraform 등)을 연달아 찾았습니다. 로그를 근거로 숨김 파일 경로를 막는 규칙을 추가하고, 인증서 발급에 쓰이는 /.well-known/ 경로는 예외로 두어 정상 동작까지 확인했습니다.

2. "빨라집니다"는 항상 맞는 말이 아닙니다

적용 전 응답 헤더를 보니, 원래 서버는 이미 다른 CDN(Fastly)을 거쳐 서비스되고 있었습니다. Cloudflare를 연결한 뒤 얻은 것은 속도가 아니라 보안 규칙, 차단 기록, SSL 정책에 대한 통제권이었습니다. 이미 CDN을 쓰는 고객이라면, 대체할지 보안 계층으로만 더할지부터 함께 정해야 한다는 것을 배웠습니다.
